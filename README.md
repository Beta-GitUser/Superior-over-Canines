# Better than Minetest
A Luanti game project that aims to recreate/port Better than Wolves, with fully custom content.


# What is Better than Wolves?
It's a Minecraft mod by FlowerChild that initially aimed to be a technology mod, just to become a challenge mod later. It combined semi-realism and relative unfairness to the player.

# Install instructions:
As of right now i didn't uploaded this project to ContentDB, neither i'm making releases (they're just repository snapshots at most)... Just download the repository as .zip and install it into the "games" folder in the Luanti folder. Just remember: If it doesn't pop up, check if it has minetest.conf in this place: "luanti/games/Superior-over-Canines/minetest.conf" and not "luanti/games/random folder/Superior-over-Canines/minetest.conf"
Reminder, i usually never push an untested update into main branch (which as of writing is the only one).
